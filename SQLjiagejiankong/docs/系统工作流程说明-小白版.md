## 💰 比较的是什么价格？

### 答案：**日常价和活动价都会比较！**

系统会**同时监控两种价格**：

### 比较逻辑（在 `priceMonitor.js` 第58-60行）

```javascript
// 第58行：检查日常价是否变化
const dailyChanged = this.checkPriceChange(latest.daily_price, dailyPrice);

// 第60行：检查活动价是否变化
const promoChanged = this.checkPriceChange(latest.promo_price, promoPrice);
```

### 触发通知的条件

**只要满足以下任意一个条件，就会发送钉钉通知：**

1. ✅ 日常价变化超过 **5元**
2. ✅ 活动价变化超过 **5元**
3. ✅ 两者都变化了

### 比较规则详解

| 情况 | 上次价格 | 这次价格 | 变化值 | 是否通知 |
|------|---------|---------|--------|---------|
| 日常价变动 | 255元 | 260元 | +5元 | ✅ 通知 |
| 日常价小变 | 255元 | 257元 | +2元 | ❌ 不通知 |
| 活动价新增 | 无活动价 | 200元 | 新增 | ✅ 通知 |
| 活动价取消 | 200元 | 无活动价 | 取消 | ✅ 通知 |
| 活动价变动 | 200元 | 180元 | -20元 | ✅ 通知 |

### 阈值配置

在 `config.js` 第7行：
```javascript
priceThreshold: 5,  // 价格变化阈值：5元
```

💡 **你可以修改这个数字**：
- 改成 `1` → 只要变1元就通知（很敏感）
- 改成 `10` → 变化超过10元才通知（不太敏感）

## 📱 如何接收价格变动通知？

### 通知方式：**钉钉机器人**

### 通知流程

```
价格变了 → notifier.js (第77行) → 调用钉钉API → 你的手机收到消息
```

### 通知内容示例

```
【价格变动提醒】
商品：颜色:蔡司新清锐变色... | 镜片折射率:1.56(较薄)

日常价：255 → 260
活动价：200 → 180

时间：2026-10-31 10:30:45
```

### 配置钉钉机器人

在 `config.js` 第8-11行：
```javascript
dingtalk: {
  webhook: process.env.DINGTALK_WEBHOOK || '',  // 钉钉机器人 Webhook 地址
  secret: process.env.DINGTALK_SECRET || ''     // 钉钉机器人密钥
}
```

### 如何设置？

**方法1：修改配置文件**
```javascript
dingtalk: {
  webhook: 'https://oapi.dingtalk.com/robot/send?access_token=你的token',
  secret: '你的密钥'
}
```

**方法2：使用环境变量（推荐，更安全）**
```bash
export DINGTALK_WEBHOOK="https://oapi.dingtalk.com/robot/send?access_token=你的token"
export DINGTALK_SECRET="你的密钥"
```

### 如果没配置会怎样？

- ⚠️ 系统会正常运行
- ⚠️ 价格会正常保存到数据库
- ⚠️ 但不会发送通知（因为没有机器人地址）
- ✅ 可以通过查看日志文件知道是否有变动

### 其他获取信息的方式

#### 方式1：查看日志文件

## 💡 小白常见疑问

### Q1: 我不小心删除了数据库怎么办？
**A:** 别担心！我们刚做了迁移时生成了备份：
```bash
# 恢复备份
cd SQLjiagejiankong/data
cp price_monitor_backup_1793426946376.db price_monitor.db
```

### Q2: 影刀抓取失败会怎样？
**A:** 系统会：
- ❌ 读取不到 `current_price.json` 文件
- 📝 在日志中记录错误
- 📱 如果配置了钉钉，会发送异常通知
- ⏸️ 本次监控跳过，等下次抓取

### Q3: 数据库会不会越来越大？
**A:** 不会！系统会**自动清理**超过 3 天的旧数据（在 `config.js` 中配置）

### Q4: 前端网页打不开怎么办？
**A:** 检查：
1. 是否运行了 `node web-ui.js`
2. 端口 3000 是否被占用
3. 数据库文件是否存在

### Q5: 我想改价格阈值怎么办？
**A:** 编辑 `config.js` 文件：
```javascript
priceThreshold: 5,  // 改成你想要的数字
```
